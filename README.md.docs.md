# Documentation de `README.md`

## Role du fichier actuel

`README.md` est encore le README par defaut du template React + Vite. Il explique le template de depart, mais il ne decrit pas encore le projet MaxCanva qui existe maintenant dans `src/App.jsx`.

## Ce que contient actuellement le README

Le contenu present explique:

- comment React fonctionne avec Vite;
- quels plugins React sont disponibles;
- pourquoi React Compiler n'est pas active par defaut;
- comment etendre la configuration ESLint;
- une recommandation generale vers TypeScript.

## Ce que le README ne couvre pas encore

Dans son etat actuel, il ne documente pas:

- l'objectif de MaxCanva;
- les fonctionnalites de dessin et simulation;
- la structure des ecrans et des interactions;
- la facon d'utiliser l'outil;
- les choix techniques du prototype.

## Conclusion sur ce fichier

Le README actuel reste utile pour comprendre la base Vite/React, mais il est desormais incomplet par rapport au vrai contenu du projet. Il devrait idealement etre remplace ou reecrit pour documenter MaxCanva lui-meme.

## Resume

`README.md` est un document herite du scaffold initial. Il ne pilote pas l'application, mais il merite une mise a jour si vous souhaitez une documentation projet coherente a l'echelle du depot.
